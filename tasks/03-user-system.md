# Task 03: User System

## Status
- **Status**: Completed
- **Completion Date**: 2026-07-10
- **Assigned to**: AI Assistant / Developer

## Objective
Enable members to manage their profiles, view their subscription states, and access role-specific functionality.

## Requirements & Scope
1. **User Profiles**:
   - Provide endpoints for users to retrieve and update personal details (first name, last name, email).
   - Support password updates securely.
2. **Subscription Management**:
   - Let members view their active `Membership` and past transaction histories.
   - Display expiration alerts and prompt renewal options when near expiration.
3. **Frontend Integration**:
   - Build a "My Dashboard" client route containing membership details, profile forms, and quick access to registered events/courses.
